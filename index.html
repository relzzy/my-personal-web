02 // FULL-STACK FLAGSHIP PRODUCTION SAAS

Cue — Realtime Creator Video Review & Scheduling Engine

A multi-tenant workflow and review platform built for content creators, agencies, and brand reviewers to approve multi-slide carousels and video drafts across 7 social networks. Eliminates lost links, email clutter, and international scheduling mistakes by combining isolated client workspaces, dynamic browser timezone translation, and sub-second feedback loops.

Universal Timezone Engine Normalizes publish dates to UTC ground truth and translates to each client's browser clock via the native Intl.DateTimeFormat API.
Multi-Tenant Isolation Guarantees zero cross-client data leaks using PostgreSQL Row-Level Security (RLS) policies and workspace-scoped creator/reviewer roles.
4-Way Decision State Machine Enforces structured decisions (Approve, Suggest Changes, Hold, Deny) with mandatory revision guards and an atomic 1-click resubmission loop.
Sub-Second Realtime Streams PostgreSQL change streams broadcast over Supabase WebSockets to sync live review cards, revision badges, and slide-out team chat.
Next.js (App Router) TypeScript Tailwind CSS Supabase PostgreSQL RLS Realtime WebSockets Intl Timezone API Multi-Tenant RBAC Vercel

⚡ The Forward Deployed Mindset

I thrive where different disciplines intersect: AI/ML, software development, web infrastructure, and game systems. My philosophy is rooted in pragmatism: rather than treating AI as an isolated black box, I connect language models directly to real-world environments, operating system tools, and structured data stores to create dependable, self-healing systems.

🖥️ Local AI & Consumer GPU Optimization

A core focus of my research is making high-parameter models practical on local consumer hardware. I experiment heavily with llama.cpp, Ollama, vLLM, GGUF quantization, and Unsloth QLoRA fine-tuning. By engineering lightweight micro-routers and multi-stage RAG pipelines, I aim to deliver 30B-class coding and reasoning capabilities without relying on costly cloud APIs or sacrificing source code privacy.
